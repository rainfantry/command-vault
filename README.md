# Command Vault

Personal cheat sheet for CSEC operations. Searchable, categorized, copy-paste ready.

## Categories

- **VPS** — screen, netcat, systemd, receiver management
- **PowerShell** — execution policy, registry, Explorer settings
- **Defender** — threat detection checks
- **Linux** — HTTP server, SCP, general commands
- **Git** — add, commit, push

## Usage

Visit the live site: `https://rainfantry.github.io/command-vault`

Or run locally:
```bash
python -m http.server 8080
# Open http://localhost:8080
```

## Features

- Real-time search across all commands
- Filter by category tags
- One-click copy to clipboard
- Dark terminal aesthetic

---

*Built from actual operational commands. No cloud storage — everything is static HTML.*
